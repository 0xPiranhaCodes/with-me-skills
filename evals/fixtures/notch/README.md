# Notch
A habit tracker with no streaks, no guilt and no nagging.

Notch shows a few habits and a strip of dots. Tap to notch today; miss a day and nothing happens. Tap any dot to add a short note, like why you skipped it. Data stays in your browser.

## Install
No install. Serve the folder statically and open it (installable as a PWA).

## Quick start
```
python3 -m http.server 8000
# open http://localhost:8000
node --test
```

See [ARCHITECTURE.md](ARCHITECTURE.md).

## Contributing
Keep it small. No streaks, points or reminders (see docs/brief.md non-goals).
