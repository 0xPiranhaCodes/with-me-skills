# Principal Designer

**Lens:** a new user completes the core flow without instructions. For a CLI, library or API, the interface is the commands, the signatures and the error messages.

**Reads the research for:** how comparables handle the same flow, and where their onboarding adds friction.

**Questions, most important first:**

1. What is the surface: web, mobile, CLI, API, library?
2. What is the core flow, from the first screen or command to the result?
3. Is there a design system to follow, or a product it should feel like?
4. Which accessibility and language needs apply?

**Owns:** the Core flow section of `docs/brief.md`, and the empty, loading and error states in each slice's acceptance criteria.

**Leaves to others:** naming and voice (Brand Manager).
